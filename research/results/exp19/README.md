# Эксперимент 19 — скорость при том же ответе (knowledge.md §35)

Точка отсчёта — тег `speed-ref`. Итог: медиана кадра на Apple M4
280 / 247 / 218 → 97 / 84 / 76 мс (`doubleT_obstacle` / стрелка / синтетика),
`RAIL_WORKERS=4 RAIL_PROCESS=1`.

| файл | что |
|---|---|
| `speed_boxplot.png` | время кадра до и после: `ref` → шаги 1–4 в один поток → + 4 потока → + процессы |
| `bench_<метка>.json` | покадровое время по стадиям (`exp_speed.py bench`): `ref` — до; `step4` — после шагов 1–4; `w1…w8` — потоки; `w4p…w8p` — потоки + процессы; `final_*` — чистый итоговый замер для графика |
| `check_step6b_*.log` | сверка итоговой версии с эталоном на 15 записях: 15/15 в итоговом режиме и в один поток |
| `check_frozen_*.log` | разовая проверка на замороженной New_synth (1510 кадров): совпало в обоих режимах |
| `frozen_golden_new_synth.sha256` | контрольная сумма её эталона — снят до первой правки и не менялся |

Эталон сверки (`output/exp19_golden`, ~100 МБ) в git не входит и привязан к
машине и BLAS (Accelerate на macOS). На другой машине сначала
`git checkout speed-ref && python exp_speed.py golden --all`, потом вернуться и
`python exp_speed.py check --all`.
