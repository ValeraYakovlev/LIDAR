# Эксперимент 21. Низкие предметы на рельсах: коробка на `doubleT_obstacle`

**Задача (заказчик, 2026-09-27):** чтобы коробка на левом рельсе
`doubleT_obstacle` (кадры 50–200, 56.4 м) определялась после того, как её
положили.

**Статус: проведён, knowledge.md §37.** `low_rest_b0`: коробка 92 / 100 из 125 (исх. / зерк.), новых ложных на 32 записях нет; `low_rest` (назначенный основным) — 59 / 71, критерий «≥ половины» на исходной не прошёл. Слепой проверки нет.

**Ветка:** `feature/low-objects` (от `feature/double-track` 848250f). База —
`final_b2_f`: `final_b2` с исправленным профилем по высоте (§36), он на всей
разработке совпадает с `final`, коробку не находит (0 из 125).

**Отложенных данных нет.** Все записи использованы (§31, §34, §36). Поэтому:
правило выводится из физики и разрешения лидара, а не из чисел коробки;
проверяется на ВСЕХ низких предметах, какие есть, и на ложных по ВСЕМ записям
с зеркалами. Результат — «проверено на разработке», не слепо.

## Что видно в данных (до правки)

Коробка на 56 м — один луч лидара: три ячейки по 10 см поперёк (u −1.0…−0.8)
на 0.14–0.16 м над плоскостью головок (профиль §36), до того как её положили —
полотно на −0.12…−0.05 м. В габарит `final_b2_f` (низ 0.133 м на 56 м) попадает
3 вокселя в 73 кадрах из 125, 2 — в 31. Порог скопления на 56 м — 3.1: половина
ожидаемого числа лучей на предмет 0.25 × 0.25 м (≈3 столбца × 2 кольца).

## Гипотеза

Обязательство «видим предмет 0.25 × 0.25 м» для предмета, стоящего на пути,
означает: в габарит заходит только его часть выше низа габарита — `0.25 − низ(D)`
(0.12 м на 56 м, меньше одного шага колец). Ожидать от неё два кольца нельзя.
Порог по высоте — от этой части: `need = frac · столбцы(0.25) · max(1, (0.25 − низ(D)) / шаг колец(D))`,
не меньше `floor` = 3.

Варианты (все поверх `final_b2_f`):
- `low_rest` — порог по высоте от части предмета выше низа габарита;
- `low_rest_b0` — то же и низ без запаса (0.10 м);
при необходимости — только для скоплений у низа габарита.

## Мерило (зафиксировано до правки)

Предметы:
- коробка `doubleT_obstacle`, кадры 76–200 (после ухода человека): подтверждённых
  кадров из 125; человек — не хуже 61 из 72;
- New_synth 3 (0.3 м на рельсах) и 9 (длинный низкий на рельсах, 0.10–0.30):
  дальность подтверждения и непрерывность;
- старая синтетика `box` (низкая коробка на кривой) и остальные предметы — не хуже.

Ложные подтверждённые — по всем записям: реальные 6 + зеркала 6, старая
синтетика 3, New_synth, синтетика выезда 8 + зеркала 8. `roundT_doubleT` —
отдельной строкой (там уже 24 / 21 ложных от пути, §36).

**Успех:** коробка подтверждена в заметной доле кадров (≥ половины) и на
зеркальной копии тоже, при нуле новых подтверждённых ложных на всех записях
(кроме объяснённых по кадрам). Любая новая ложная — разбор по GIF.

## Риски

- Порог снижается везде, не только у коробки, — отсюда мерило по всем записям.
- На 56 м от коробки один луч: на другой дальности тот же предмет может
  попасть между кольцами. Смотреть непрерывность, а не только число кадров.
- Поезд в `doubleT_obstacle` стоит: подтверждение «3 из 5» для неподвижного
  предмета здесь проще, чем на ходу.
